### What You Need to Do in Your Email Filtering Repository:

1. **Add this as a submodule**:
   ```bash
   git submodule add https://github.com/MattyStacks/seive-email-filtering-mcp-server.git tools/sieve-mcp-server
   ```

2. **Copy VS Code configuration** from `examples/copilot_integration_example.md`

3. **Create context files** so Copilot understands Sieve syntax

4. **Use CLI commands** in your development workflow

### Automatic GitHub Copilot Invocation

**The MCP server will be invoked when:**
- You work on `.sieve` files (proper file associations set up)
- You use VS Code tasks (Ctrl+Shift+P → "Tasks: Run Task")
- You reference Sieve filtering patterns in comments
- Copilot sees the context files and examples

**Example workflow that will trigger Copilot to use your server:**
```sieve
# Create a spam filter that moves messages to Junk folder
# TODO: Add spam detection rules
```
→ Copilot will suggest using patterns from your MCP server examples
