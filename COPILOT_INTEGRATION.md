# GitHub Copilot Integration for Sieve Email Filtering

This document explains how to integrate the Sieve Email Filtering MCP Server with GitHub Copilot and VS Code for enhanced email filter development.

## Current Status

GitHub Copilot doesn't natively support MCP servers like Claude Desktop does. However, you can still leverage this server's capabilities when working on Sieve email filtering projects.

## Integration Options

### Option 1: VS Code Extension (Recommended)
Create a VS Code extension that integrates with this MCP server:

1. **Extension Structure:**
   ```
   sieve-copilot-extension/
   ├── package.json
   ├── src/
   │   ├── extension.ts
   │   └── mcpClient.ts
   └── README.md
   ```

2. **Extension Features:**
   - Command palette integration
   - Sieve syntax highlighting
   - Auto-completion for common patterns
   - Integration with this MCP server

### Option 2: Workspace Integration
Set up your email filtering repository to automatically use this server:

1. **Add to your email filtering project's `.vscode/settings.json`:**
   ```json
   {
     "python.terminal.activateEnvironment": true,
     "terminal.integrated.env.windows": {
       "SIEVE_MCP_SERVER_PATH": "C:\\Users\\{username}\\repos\\seive-email-filtering-mcp-server"
     },
     "github.copilot.enable": {
       "*": true,
       "yaml": true,
       "plaintext": true,
       "sieve": true
     }
   }
   ```

2. **Create a `.copilot/` directory in your email filtering project:**
   ```
   your-email-filtering-project/
   ├── .copilot/
   │   ├── context.md
   │   └── examples/
   │       ├── spam-filter.sieve
   │       ├── mailing-list.sieve
   │       └── vacation.sieve
   ```

### Option 3: Use as Reference Library
Include this project as a git submodule or reference in your email filtering repository:

```bash
# In your email filtering repository
git submodule add https://github.com/MattyStacks/seive-email-filtering-mcp-server.git tools/sieve-mcp-server
```

## Setting Up Context for Copilot

### 1. Create Context Files
In your email filtering project, create these files to help Copilot understand Sieve syntax:

**`.copilot/context.md`:**
```markdown
# Sieve Email Filtering Context

This project uses Sieve (RFC 5228) email filtering language.

## Available MCP Server Tools
- create_spam_filter
- create_mailing_list_filter
- create_sender_filter
- create_domain_filter
- create_subject_filter
- create_size_filter
- create_vacation_response
- create_blacklist_filter
- create_whitelist_filter
- generate_sieve_script
- validate_sieve_script

## Common Patterns
[Include examples from the MCP server]
```

### 2. Add Example Files
Create example Sieve files that Copilot can learn from:

**`examples/spam-filter.sieve`:**
```sieve
# Generated by Sieve MCP Server
require "fileinto";

if anyof (
    header "X-Spam-Flag" "YES",
    header :matches "X-Spam-Status" "*Yes*",
    header :contains "Subject" ["***SPAM***", "[SPAM]"]
) {
    fileinto "Spam";
    stop;
}
```

### 3. VS Code Tasks Integration
Add tasks to your email filtering project's `.vscode/tasks.json`:

```json
{
    "version": "2.0.0",
    "tasks": [
        {
            "label": "Generate Sieve Script",
            "type": "shell",
            "command": "python",
            "args": [
                "-m", "seive_email_filtering_mcp_server.cli",
                "template", "comprehensive_filtering",
                "--output", "generated.sieve"
            ],
            "group": "build",
            "presentation": {
                "echo": true,
                "reveal": "always"
            },
            "options": {
                "cwd": "${env:SIEVE_MCP_SERVER_PATH}"
            }
        },
        {
            "label": "Validate Sieve Script",
            "type": "shell",
            "command": "python",
            "args": [
                "-m", "seive_email_filtering_mcp_server.cli",
                "validate", "${file}"
            ],
            "group": "test",
            "options": {
                "cwd": "${env:SIEVE_MCP_SERVER_PATH}"
            }
        }
    ]
}
```

## Claude Desktop Integration (Alternative)
If you want to use Claude Desktop instead of/alongside GitHub Copilot:

1. **Install Claude Desktop**
2. **Configure MCP Server** in `%APPDATA%\Claude\claude_desktop_config.json`:
   ```json
   {
     "mcpServers": {
       "seive-email-filtering": {
         "command": "python",
         "args": ["-m", "seive_email_filtering_mcp_server.server"],
         "cwd": "C:\\Users\\{username}\\repos\\seive-email-filtering-mcp-server",
         "env": {}
       }
     }
   }
   ```

## Commands for Integration

### In PowerShell/Terminal:
```powershell
# Test MCP server
cd C:\Users\{username}\repos\seive-email-filtering-mcp-server
python -m seive_email_filtering_mcp_server.cli list-templates

# Generate a template
python -m seive_email_filtering_mcp_server.cli template comprehensive_filtering --output my-filters.sieve

# Create specific filters
python -m seive_email_filtering_mcp_server.cli spam-filter --mailbox Junk --output spam.sieve
```

### In Your Email Filtering Project:
1. Reference this server's utilities
2. Use the CLI commands in your build process
3. Include generated examples for Copilot to learn from

## Recommendations

1. **For immediate use**: Set up workspace integration with context files
2. **For better experience**: Create a VS Code extension that wraps this MCP server
3. **For team use**: Include this as a submodule or package dependency
4. **For AI assistance**: Use Claude Desktop with MCP integration alongside VS Code with Copilot

The MCP server will be most effective when combined with proper context setup and example files that help Copilot understand the Sieve email filtering domain.
